# saml3dwell

Приложение на базе `@equinor/videx-3d`: 3D-сцена лицензионных контуров, устьев скважин и поверхностей. Все входные координаты — **WGS84** (долгота, широта в градусах). Сцена переводится в местные метры классом `CRS` библиотеки: ось X — восток, Y — вверх, север — −Z, как у `UtmArea`. Проекция — UTM на эллипсоиде WGS84, а не ED50 из `getProjectionDefFromUtmZone`.

## Запуск

```bash
cd saml3dwell
npm install
npm run dev
```

Сборка и тесты:

```bash
npm test
npm run build
```

Кнопка «Загрузить пример» читает файлы из `public/samples`.

## Что можно загрузить

### Контуры лицензий — GeoJSON

`Polygon`, `MultiPolygon`, `LineString` и `MultiLineString`. Контур можно также задать вершинами (долгота, широта) или вставить GeoJSON в форму. Отметка плоскости задаётся в метрах, положительная вверх. Включите «Объём лицензии», чтобы опустить контур до подошвы загруженных поверхностей.

### Устья — GeoJSON

`Point` и `MultiPoint`. Амплитуда ротора (альтитуда стола ротора, м над уровнем моря) берётся из свойств:

`амплитуда_ротора`, `альтитуда_ротора`, `kb`, `rotaryElevation`, `elevation`, `z`

Если свойства нет, используется третья координата точки. Устье можно добавить вручную.

### Поверхности — ESRI ASCII Grid

```
ncols        36
nrows        30
xllcorner    73.26
yllcorner    61.16
cellsize     0.008
NODATA_value -9999
```

`xllcorner` / `yllcorner` (или `xllcenter` / `yllcenter`) — градусы WGS84. Значения ячеек — отметки в метрах. Если в файле глубина положительна вниз, включите переключатель «Значения — глубина».
