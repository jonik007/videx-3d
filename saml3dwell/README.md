# saml3dwell

Приложение на базе `@equinor/videx-3d`: 3D-сцена лицензионных контуров, устьев скважин, поверхностей и кубов свойств. Контуры, устья и сетки — **WGS84** (долгота, широта в градусах). Куб Eclipse GRDECL может быть в градусах или в метрах UTM. Сцена переводится в местные метры классом `CRS` библиотеки: ось X — восток, Y — вверх, север — −Z, как у `UtmArea`. Проекция — UTM на эллипсоиде WGS84, а не ED50 из `getProjectionDefFromUtmZone`.

## Запуск

```bash
cd saml3dwell
npm install
npm run dev
```

Сборка и тесты:

```bash
npm test
npm run build
```

Кнопка «Загрузить пример» читает файлы из `public/samples`.

## Что можно загрузить

### Контуры лицензий — GeoJSON

`Polygon`, `MultiPolygon`, `LineString` и `MultiLineString`. Контур можно также задать вершинами (долгота, широта) или вставить GeoJSON в форму. Отметка плоскости задаётся в метрах, положительная вверх. Включите «Объём лицензии», чтобы опустить контур до подошвы загруженных поверхностей.

### Устья — GeoJSON

`Point` и `MultiPoint`. Амплитуда ротора (альтитуда стола ротора, м над уровнем моря) берётся из свойств:

`амплитуда_ротора`, `альтитуда_ротора`, `kb`, `rotaryElevation`, `elevation`, `z`

Если свойства нет, используется третья координата точки. Устье можно добавить вручную.

### Поверхности — ESRI ASCII Grid

```
ncols        36
nrows        30
xllcorner    73.26
yllcorner    61.16
cellsize     0.008
NODATA_value -9999
```

`xllcorner` / `yllcorner` (или `xllcenter` / `yllcenter`) — градусы WGS84. Значения ячеек — отметки в метрах. Если в файле глубина положительна вниз, включите переключатель «Значения — глубина».

### Куб свойств — Eclipse GRDECL

Corner-point: `SPECGRID` или `DIMENS`, `COORD`, `ZCORN`, необязательный `ACTNUM` и массивы свойств размера NX·NY·NZ (`PORO`, `PERMX` и другие). Декартова сетка: `DX`, `DY`, `DZ`, `TOPS` и необязательный `MAPAXES`. Повторы `5*0.2` и форма `1.5D1` читаются. `INCLUDE` не раскрывается.

Если модуль координат столбов не больше 180 по X и 90 по Y, столбы считаются долготой и широтой WGS84. Иначе это метры UTM: зону можно задать в панели (по умолчанию 43N). Z по умолчанию — глубина, положительная вниз. На сцене рисуются наружные грани активных ячеек, цвет — шкала выбранного свойства. Срезы I, J и K оставляют ячейки с индексом меньше выбранного.
